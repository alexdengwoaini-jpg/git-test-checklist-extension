# 扩展图标说明

## 图标要求

为了让你的 VS Code 扩展在市场上更专业和醒目，需要准备一个扩展图标。

### 规格要求
- **尺寸**: 128x128 像素
- **格式**: PNG
- **文件名**: `icon.png`
- **位置**: 放在此目录下 (`vscode-extension/images/icon.png`)

### 设计建议

1. **简洁明了**: 图标应该清晰表达扩展功能
2. **高对比度**: 确保在浅色和深色主题下都清晰可见
3. **专业性**: 避免使用过于花哨的设计

### 推荐设计元素

对于 "Git 测试清单生成器"，可以考虑以下元素：
- ✅ 复选框/清单图标
- 🔍 Git 分支图标
- 📋 文档/列表图标
- 🧪 测试管图标

### 在线工具推荐

如果你不是设计师，可以使用以下在线工具快速创建图标：

1. **Canva** (https://www.canva.com/)
   - 免费在线设计工具
   - 有很多图标模板

2. **Figma** (https://www.figma.com/)
   - 专业设计工具
   - 支持协作

3. **IconKitchen** (https://icon.kitchen/)
   - 专门用于生成应用图标

4. **Favicon.io** (https://favicon.io/)
   - 快速生成简单图标

### 使用 Emoji 作为临时图标

如果暂时没有设计图标，可以用 emoji 快速创建一个：

```bash
# 使用在线工具将 emoji 转换为 PNG
# 例如: ✅ 或 📋
```

推荐网站：
- https://emojipng.com/
- https://emoji.gg/

### 色彩建议

- **主色**: 
  - 蓝色 (#007ACC) - VS Code 官方色
  - 绿色 (#28A745) - 代表测试通过
  - 橙色 (#FFA500) - 醒目

- **辅色**: 
  - 白色 (#FFFFFF) - 清晰对比
  - 深灰 (#1E1E1E) - 专业感

### 临时占位图标

如果现在没有图标，可以暂时删除 `package.json` 中的这一行：

```json
"icon": "images/icon.png",
```

扩展仍然可以正常工作，只是没有自定义图标。

### 制作步骤（使用 Canva）

1. 访问 https://www.canva.com/
2. 创建自定义尺寸: 128x128 像素
3. 选择背景色
4. 添加图标元素（搜索 "checklist", "git", "test"）
5. 调整布局
6. 下载为 PNG 格式
7. 重命名为 `icon.png`
8. 放在 `vscode-extension/images/` 目录下

### 检查图标

```bash
# 确认图标文件存在
dir images\icon.png

# 确认尺寸正确（128x128）
# 可以在 Windows 中右键 -> 属性 -> 详细信息查看
```

---

**提示**: 即使没有图标，扩展也能正常工作。你可以先安装使用，之后再添加图标。
